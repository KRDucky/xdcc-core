# Security reporting

XDCC Core is at M0 bootstrap and has no implemented protocol or transfer handling.
No release is supported for production use yet.

## Private reports

Report suspected vulnerabilities privately to
[sec.krd.hub@proton.me](mailto:sec.krd.hub@proton.me).
Do not post exploit details, credentials, or sensitive captures in public issues.

Useful report details include the affected commit,
reproduction steps, expected and actual behavior, and a sanitized test case.

The proposed threat model and controls are in [docs/SECURITY.md](docs/SECURITY.md).
They describe planned behavior, not implemented protections.
